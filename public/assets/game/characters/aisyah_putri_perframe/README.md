# Aisyah Putri — Phaser 3 individual frames

- 16 individual PNG files
- Canvas per frame: 64 × 64 px (RGBA, transparent)
- Directions: down, left, up, right
- 4 frames per direction

## Filenames
- aisyah_down_1.png … aisyah_down_4.png
- aisyah_left_1.png … aisyah_left_4.png
- aisyah_up_1.png … aisyah_up_4.png
- aisyah_right_1.png … aisyah_right_4.png

In Phaser, load each frame as a separate texture or combine them into a spritesheet later.
