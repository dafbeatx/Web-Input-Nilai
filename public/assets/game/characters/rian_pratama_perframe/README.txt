RIAN PRATAMA - INDIVIDUAL CHARACTER FRAMES

16 separate transparent PNG files. No combined spritesheet is included.
Each frame is 64 x 64 px (RGBA). Full body is fitted inside the canvas.

Folders: down (front), left, up (back), right.
Each direction has four sequential frames: 1, 2, 3, 4.

Phaser 3: load each PNG as an image, then register animations using the
individual texture keys. These are individual frames, not a Phaser spritesheet.
